# netspeed-toolkit

純前端網頁測速工具（單一 `index.html`，免安裝、免建置），內含兩大功能分頁：**網速上限測試**與**網站連線測速與穩定度測試**，並提供除錯紀錄面板協助排查網路問題。

## 功能特色

### 1. 網速上限測試
- 依序執行「延遲 → 下載 → 上傳」完整測速流程，使用 Cloudflare 公開測速節點（`speed.cloudflare.com`）。
- 下載／上傳採**持續測試＋區塊大小自動調整**：依可調整的測試時長（秒）反覆傳輸，並依上一輪實測速度動態調整區塊大小（每輪約 2～2.5 秒），取瞬時峰值作為頻寬上限估計，結果較單次測試更穩定準確。
- 延遲測試同時計算平均延遲與延遲抖動（Jitter，以標準差計算）。
- 可調參數：延遲測試次數、下載／上傳測試時長、單次逾時時間、儀表板顯示上限（Mbps）。
- **雙檢視顯示**：可切換「儀表板顯示」（下載／上傳各一個半圓儀表，測試中會有脈動光暈與呼吸動畫的即時效果）或「數字列表顯示」（即時數值卡片），選擇會記憶在瀏覽器本機。
- 測試完成後顯示下載／上傳峰值、平均延遲、抖動的總結卡片，並自動累積**測試紀錄表**（含時間戳記，同一頁面多次測試可互相比較）。

### 2. 網站連線測速與穩定度測試
- 內建常用網站清單，依分類分組：🔍 搜尋引擎（Google、Bing、Yahoo）、👥 社群媒體（Facebook、Instagram、X、Threads、LinkedIn）、🎬 影音串流（YouTube、Netflix、Twitch、巴哈動畫瘋、bilibili）、🎮 遊戲平台（Steam、Epic Games、Ubisoft），可個別勾選、整組全選／取消全選。
- 支援**自訂新增網站**（輸入名稱與網址即可，會自動組出 favicon 探測位址），自訂清單會保存在瀏覽器本機（localStorage），重新整理後仍會保留。
- 以各網站 favicon 圖示資源作為探測目標量測往返時間（RTT），可調整每站測試次數、測試間隔、逾時時間；採 4 個網站同時併發測試以縮短總時間。
- 結果表格提供每個網站的：平均延遲、最小／最大延遲、抖動、遺失率（%）、**穩定度分數與評級徽章**（穩定／普通／不穩定，依延遲、抖動、遺失率綜合計算）、以及延遲趨勢走勢圖（sparkline）。
- 表格欄位可點擊表頭排序（含遞增／遞減切換）。
- 點擊任一列可**展開詳細面板**，列出每一次探測的成功／失敗結果、實際回應時間與相對長條圖，方便觀察單站的穩定度變化。
- 展開面板內建**一鍵複製 tracert／traceroute 診斷指令**，會自動偵測作業系統（Windows／Mac／Linux）並帶入正確的指令與目標主機名稱，方便使用者貼到終端機進一步排查路由問題。
- 測試結果可一鍵**匯出為 CSV** 檔案，方便留存或進一步分析。

### 除錯與環境偵測
- 內建可收合的「除錯紀錄 Debug Log」面板，測速過程中的每個步驟（連線、進度、成功／失敗原因）都會即時記錄下來，並支援複製全部紀錄或清除紀錄。
- 提供「快速連線檢測」按鈕，會分別測試 trace 端點、小型下載與小型上傳請求，快速判斷是否為網路環境問題。
- 自動偵測目前頁面的執行環境（例如 `file://` 開啟、或在非一般瀏覽器分頁的預覽／沙盒視窗中開啟），並在偵測到可能導致測速必定失敗的情況時，於頁面上方顯示提示訊息與建議解法。

### 其他
- 支援深色／淺色主題切換，並記住使用者偏好。
- 純前端實作，不需伺服器端程式或任何套件安裝，下載後以瀏覽器開啟 `index.html` 即可使用（若使用 `file://` 開啟遇到跨網域限制，建議改用本機伺服器，例如 `python3 -m http.server`，再以 `http://localhost` 開啟）。

## 注意事項
- 測速結果會受裝置效能、Wi-Fi／有線網路環境、ISP 路由及背景網路流量影響，僅供相對比較參考，非正式頻寬保證值。
- 網站連線測試若被瀏覽器擴充功能（如廣告攔截器）或目標網站的 CSP 政策攔截請求，該次結果會被視為逾時失敗，可能影響遺失率數據。
